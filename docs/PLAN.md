# SCARY – Horror Launcher for Android TV

> מסמך אפיון ותוכנית עבודה. סטטוס: **שלב 1 בפיתוח** (ההחלטות אושרו, ראו סעיף 2).
> הדמיה אינטראקטיבית: [`mockup/launcher-mockup.html`](../mockup/launcher-mockup.html)

## 1. מטרת המוצר

לאנצ׳ר (מסך בית) שמחליף את מסך הבית של Android TV, בנוי כולו בחוויית סרטי אימה, ומרכז במקום אחד:
- מאגר סרטי אימה ומתח פסיכולוגי (מטא־דאטה בלבד: פוסטר, שנה, במאי, תקציר, "מד פחד").
- קיצורים לאפליקציות: Stremio, חנות Play, YouTube ושאר האפליקציות המותקנות.
- בחירה בסרט פותחת אותו באפליקציית צפייה מותקנת (בראש ובראשונה Stremio).

**האפליקציה לא מזרימה ולא מאחסנת וידאו.** היא שכבת ניווט ותוכן מעל אפליקציות קיימות.

## 3. MVP – היקף

**בפנים:**
1. מסך בית: סרגל עליון (שעה, חיפוש, הגדרות, מתג אפקטים), Hero לסרט נבחר, שורות תוכן.
2. שורות: "המשך צפייה" (מקומי), "האפליקציות שלי", קלאסיקות, מתח פסיכולוגי, תתי־ז׳אנרים.
3. עמוד סרט: פרטים, "מד פחד", כפתורי "צפייה ב־Stremio", "טריילר", "לרשימה שלי".
4. מגירת כל האפליקציות המותקנות + הצמדה/הסתרה/סידור.
5. חיפוש במאגר (טקסט; קולי כשלב 2).
6. הגדרות: שורות, אפליקציות, אפקטים, צלילים, נעילת הורים ב־PIN, שפה.
7. אווירה: ערפל, גרעיניות פילם, תאורה "נושמת", צלילים (כבויים כברירת מחדל).

**בחוץ (שלבים הבאים):** חשבונות וסנכרון, המלצות מותאמות, תוספי Stremio משלנו, ווידג׳טים, Live wallpaper, תמיכה ב־Fire TV.

## 4. User Stories

- כצופה, אני רוצה שהטלוויזיה תיפתח ישר למסך אימה, כדי להרגיש את האווירה מהשנייה הראשונה.
- כצופה, אני רוצה לדפדף בשורות לפי תת־ז׳אנר ו"מד פחד", כדי לבחור סרט לפי מצב הרוח.
- כצופה, אני רוצה ללחוץ על סרט ולהגיע ישר ל־Stremio, בלי לחפש שוב.
- כצופה, אני רוצה גישה מהירה לחנות Play ולכל האפליקציות שלי מאותו מסך.
- כהורה, אני רוצה לנעול תוכן מעל דירוג גיל מסוים ב־PIN.
- כמשתמש רגיש לתנועה/הבהובים, אני רוצה לכבות את כל האפקטים במתג אחד.
- כמשתמש, אני רוצה שהלאנצ׳ר יעבוד גם בלי אינטרנט (מטמון מקומי).

## 6. ארכיטקטורה

```
┌───────────────────────── Android TV device ─────────────────────────┐
│  SCARY Launcher (Kotlin)                                            │
│  ┌──────────── UI: Jetpack Compose for TV ────────────┐             │
│  │ Home · Details · Search · AllApps · Settings · PIN │             │
│  └───────────────┬────────────────────────────────────┘             │
│        ViewModels (StateFlow)                                       │
│  ┌───────────────┴──────────── Domain ───────────────────┐          │
│  │ CatalogRepository · AppsRepository · LaunchService    │          │
│  │ ParentalLockService · SettingsRepository             │          │
│  └──────┬──────────────┬──────────────────┬─────────────┘          │
│   Room (cache)   PackageManager      DataStore (settings,          │
│   + Coil images  (installed apps)    PIN hash)                      │
└─────────┬───────────────────────────────────────────────────────────┘
          │ HTTPS (read-only)
     TMDB API  ──  רק מטא־דאטה ותמונות, ללא מידע אישי
```

- **הפעלת אפליקציות:** `PackageManager.getLeanbackLaunchIntentForPackage()` עם נפילה ל־`getLaunchIntentForPackage()`.
- **פתיחת סרט ב־Stremio:** Deep link לפי IMDb ID. הפורמט המדויק **דורש אימות מול התיעוד הרשמי של Stremio**; אם אין deep link יציב, נפתח את האפליקציה בלבד ונציג הודעה.
- **חנות Play:** `market://details?id=<package>` לאפליקציה ספציפית. בחנות של Android TV חיפוש חופשי עשוי לא להיתמך באותה צורה (דורש אימות במכשיר).
- **רישום כמסך בית:** `intent-filter` עם `MAIN` + `HOME` + `DEFAULT` + `LEANBACK_LAUNCHER`.

## 9. API חיצוני (קריאה בלבד)

| Endpoint (TMDB v3) | שימוש |
|--------------------|-------|
| `GET /discover/movie?with_genres=27` | אימה לפי פופולריות/עשור |
| `GET /discover/movie?with_genres=53` | מתח (בשילוב מילות מפתח לפסיכולוגי) |
| `GET /movie/{id}?append_to_response=external_ids,videos,release_dates` | פרטים, IMDb ID, טריילר, דירוג גיל |
| `GET /search/movie` | חיפוש |

אין API משלנו ב־MVP. מפתח TMDB לא נכנס לקוד: `local.properties` / CI secret ⇒ `BuildConfig`. מפתח בתוך APK ניתן לחילוץ, ולכן בהפצה ציבורית מומלץ proxy קטן (שלב 2).

## 12. Threat Model קצר

| נכס | איום | בקרה |
|-----|------|------|
| מפתח TMDB | חילוץ מה־APK | הגבלת מפתח, proxy בהפצה ציבורית |
| PIN הורים | ניחוש / קריאה מהאחסון | hash עם salt (PBKDF2), השהיה מתגברת אחרי כשלונות |
| Intents חיצוניים | פתיחת אפליקציה זדונית בשם דומה | פתיחה לפי package name מאומת מרשימת המותקנות; אין URL שרירותי מבחוץ |
| תוכן מהרשת | תגובה זדונית / MITM | HTTPS בלבד, `network_security_config` ללא cleartext, ולידציית סכמה |
| לאנצ׳ר שנתקע | המשתמש ננעל מחוץ למכשיר | גישה תמידית להגדרות המערכת, crash-safe fallback |

## 13. פרטיות

- אין חשבונות, אין אנליטיקה, אין פרסום ב־MVP. כל ההעדפות, הרשימה ו"המשך צפייה" נשמרים מקומית בלבד.
- בקשות ל־TMDB חושפות IP ושאילתות חיפוש. יש לציין זאת במדיניות הפרטיות.
- אין עוגיות (אפליקציה נייטיב). אם תתווסף אנליטיקה: רק אחרי הסכמה מפורשת, עם אפשרות משיכה.
- רשימת האפליקציות המותקנות נקראת מקומית ולא יוצאת מהמכשיר. בפרסום ב־Play נדרשת הרשאת `QUERY_ALL_PACKAGES` או `<queries>` מתאים, וזה עשוי לדרוש הצהרה לגוגל (**דורש אימות מול מדיניות Google Play**).
- מסמכי מדיניות פרטיות ותנאי שימוש יוכנו כטיוטה **ודורשים בדיקה משפטית**.

## 14. נגישות

- כל רכיב נגיש ב־D-pad, פוקוס בולט (הילת "אור נר"), סדר פוקוס הגיוני ב־RTL.
- TalkBack: `contentDescription` לכל כרטיס ואייקון, הכרזה על שינויי Hero.
- **ללא הבהובים מעל 3 פעמים בשנייה** (WCAG 2.3.1). "jump scares" חזותיים או קוליים רק כאופציה, כבויים כברירת מחדל.
- מתג אחד מכבה תנועה, ומכובד גם "הסרת אנימציות" של המערכת.
- ניגודיות AA לטקסט, גודל טקסט מינימלי מתאים למרחק צפייה (10-foot UI).

## 15. סיכונים פתוחים

1. **Google TV מגביל החלפת מסך בית.** במכשירי Google TV חדשים (למשל Chromecast with Google TV) אין תמיד אפשרות לבחור לאנצ׳ר אחר בהגדרות, ולעתים נדרשים פתרונות עקיפים (ADB, מיפוי כפתור Home). **דורש אימות על המכשיר שלך.**
2. **Deep links ל־Stremio** אינם API מתועד רשמית. ייתכן שיישבר בעדכונים.
3. **תוספי Stremio**: הלאנצ׳ר לא יתקין, ימליץ או יקשר לתוספים המספקים תוכן מפר זכויות. **נושא לבדיקה משפטית** אם האפליקציה תופץ.
4. **TMDB**: קרדיט חובה ותנאי שימוש. שימוש מסחרי דורש רישיון.
5. **פרסום ב־Google Play** של לאנצ׳ר: מדיניות הרשאות ותוכן. דורש אימות.

## 16. עדכון: רקעים, מידע ולאנצ׳ר אמיתי (בקשת משתמש)

- **מקור תמונות ומידע:** Cinemeta, שירות המטא־דאטה הציבורי של Stremio (ללא מפתח API): פוסטר, רקע, לוגו, דירוג IMDb, שחקנים, טריילר.
  נשלחים רק מזהי IMDb. מטמון בקובץ מקומי, רענון כל 24 שעות, עובד גם בלי אינטרנט. מתג כיבוי בהגדרות. **תנאי השימוש של Cinemeta והזכויות בתמונות דורשים בדיקה לפני הפצה ציבורית.**
- **עוד נתונים:** שורות "פופולרי עכשיו באימה", "מותחנים פופולריים", "תעלומות שכולם רואים" (כ־20 סרטים בכל שורה). לסרטים מהרשת אין מד פחד עריכתי, ולכן נעילת ההורים מתייחסת אליהם כרמה 5.
- **לאנצ׳ר:** בקשת תפקיד HOME מהמערכת (Android 10+), ואם המכשיר לא מציע אותה: שירות נגישות שמסנן רק את מקש Home ופותח את SCARY, וגם בעליית המכשיר. השירות לא קורא תוכן מסך.

## 17. מפתח TMDB אישי (אופציונלי)

- בהגדרות SCARY: שדה להזנת מפתח API v3 (32 תווים) או Read Access Token v4. המפתח נבדק מול TMDB לפני שמירה.
- **אחסון:** AES-256-GCM עם מפתח ב־Android Keystore. לא נכתב ללוגים, לא נשמר במטמון, נשלח רק ל־api.themoviedb.org (HTTPS, בלי redirect).
- **מה מוסיף:** שמות ותקצירים בעברית (he-IL), תמונות w1280/w500, שורות: אימה חדשה, הכי מדורגים באימה, מתח ותעלומה.
- **קרדיט חובה:** "This product uses the TMDB API but is not endorsed or certified by TMDB" מוצג בהגדרות. **תנאי השימוש של TMDB (שימוש אישי/מסחרי) דורשים בדיקה לפני הפצה.**

## 18. שפות: עברית, English, Português, Русский

- כל הממשק (122 מחרוזות) בארבע שפות. בחירת שפה בהגדרות SCARY במחזור, שמות השפות מוצגים בשפתן.
