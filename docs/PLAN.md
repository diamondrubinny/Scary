# SCARY – Horror Launcher for Android TV

> מסמך אפיון ותוכנית עבודה. סטטוס: **שלב 5 בפיתוח** (ההחלטות אושרו, ראו סעיף 2).
> הדמיה אינטראקטיבית: [`mockup/launcher-mockup.html`](../mockup/launcher-mockup.html)

## 1. מטרת המוצר

לאנצ׳ר (מסך בית) שמחליף את מסך הבית של Android TV, בנוי כולו בחוויית סרטי אימה, ומרכז במקום אחד:
- מאגר סרטי אימה ומתח פסיכולוגי (מטא־דאטה בלבד: פוסטר, שנה, במאי, תקציר, "מד פחד").
- קיצורים לאפליקציות: Stremio, חנות Play, YouTube ושאר האפליקציות המותקנות.
- בחירה בסרט פותחת אותו באפליקציית צפייה מותקנת (בראש ובראשונה Stremio).

**האפליקציה לא מזרימה ולא מאחסנת וידאו.** היא שכבת ניווט ותוכן מעל אפליקציות קיימות.

## 3. MVP – היקף

**בפנים:**
1. מסך בית: סרגל עליון (שעה, חיפוש, הגדרות, מתג אפקטים), Hero לסרט נבחר, שורות תוכן.
2. שורות: "המשך צפייה" (מקומי), "האפליקציות שלי", קלאסיקות, מתח פסיכולוגי, תתי־ז׳אנרים.
3. עמוד סרט: פרטים, "מד פחד", כפתורי "צפייה ב־Stremio", "טריילר", "לרשימה שלי".
4. מגירת כל האפליקציות המותקנות + הצמדה/הסתרה/סידור.
5. חיפוש במאגר (טקסט; קולי כשלב 2).
6. הגדרות: שורות, אפליקציות, אפקטים, צלילים, נעילת הורים ב־PIN, שפה.
7. אווירה: ערפל, גרעיניות פילם, תאורה "נושמת", צלילים (כבויים כברירת מחדל).

**בחוץ (שלבים הבאים):** חשבונות וסנכרון, המלצות מותאמות, תוספי Stremio משלנו, ווידג׳טים, Live wallpaper, תמיכה ב־Fire TV.

## 4. User Stories

- כצופה, אני רוצה שהטלוויזיה תיפתח ישר למסך אימה, כדי להרגיש את האווירה מהשנייה הראשונה.
- כצופה, אני רוצה לדפדף בשורות לפי תת־ז׳אנר ו"מד פחד", כדי לבחור סרט לפי מצב הרוח.
- כצופה, אני רוצה ללחוץ על סרט ולהגיע ישר ל־Stremio, בלי לחפש שוב.
- כצופה, אני רוצה גישה מהירה לחנות Play ולכל האפליקציות שלי מאותו מסך.
- כהורה, אני רוצה לנעול תוכן מעל דירוג גיל מסוים ב־PIN.
- כמשתמש רגיש לתנועה/הבהובים, אני רוצה לכבות את כל האפקטים במתג אחד.
- כמשתמש, אני רוצה שהלאנצ׳ר יעבוד גם בלי אינטרנט (מטמון מקומי).

## 6. ארכיטקטורה

```
┌───────────────────────── Android TV device ─────────────────────────┐
│  SCARY Launcher (Kotlin)                                            │
│  ┌──────────── UI: Jetpack Compose for TV ────────────┐             │
│  │ Home · Details · Search · AllApps · Settings · PIN │             │
│  └───────────────┬────────────────────────────────────┘             │
│        ViewModels (StateFlow)                                       │
│  ┌───────────────┴──────────── Domain ───────────────────┐          │
│  │ CatalogRepository · AppsRepository · LaunchService    │          │
│  │ ParentalLockService · SettingsRepository             │          │
│  └──────┬──────────────┬──────────────────┬─────────────┘          │
│   Room (cache)   PackageManager      DataStore (settings,          │
│   + Coil images  (installed apps)    PIN hash)                      │
└─────────┬───────────────────────────────────────────────────────────┘
          │ HTTPS (read-only)
     TMDB API  ──  רק מטא־דאטה ותמונות, ללא מידע אישי
```

- **הפעלת אפליקציות:** `PackageManager.getLeanbackLaunchIntentForPackage()` עם נפילה ל־`getLaunchIntentForPackage()`.
- **פתיחת סרט ב־Stremio:** Deep link לפי IMDb ID. הפורמט המדויק **דורש אימות מול התיעוד הרשמי של Stremio**; אם אין deep link יציב, נפתח את האפליקציה בלבד ונציג הודעה.
- **חנות Play:** `market://details?id=<package>` לאפליקציה ספציפית. בחנות של Android TV חיפוש חופשי עשוי לא להיתמך באותה צורה (דורש אימות במכשיר).
- **רישום כמסך בית:** `intent-filter` עם `MAIN` + `HOME` + `DEFAULT` + `LEANBACK_LAUNCHER`.

## 9. API חיצוני (קריאה בלבד)

| Endpoint (TMDB v3) | שימוש |
|--------------------|-------|
| `GET /discover/movie?with_genres=27` | אימה לפי פופולריות/עשור |
| `GET /discover/movie?with_genres=53` | מתח (בשילוב מילות מפתח לפסיכולוגי) |
| `GET /movie/{id}?append_to_response=external_ids,videos,release_dates` | פרטים, IMDb ID, טריילר, דירוג גיל |
| `GET /search/movie` | חיפוש |

אין API משלנו ב־MVP. מפתח TMDB לא נכנס לקוד: `local.properties` / CI secret ⇒ `BuildConfig`. מפתח בתוך APK ניתן לחילוץ, ולכן בהפצה ציבורית מומלץ proxy קטן (שלב 2).

## 12. Threat Model קצר

| נכס | איום | בקרה |
|-----|------|------|
| מפתח TMDB | חילוץ מה־APK | הגבלת מפתח, proxy בהפצה ציבורית |
| PIN הורים | ניחוש / קריאה מהאחסון | hash עם salt (PBKDF2), השהיה מתגברת אחרי כשלונות |
| Intents חיצוניים | פתיחת אפליקציה זדונית בשם דומה | פתיחה לפי package name מאומת מרשימת המותקנות; אין URL שרירותי מבחוץ |
| תוכן מהרשת | תגובה זדונית / MITM | HTTPS בלבד, `network_security_config` ללא cleartext, ולידציית סכמה |
| לאנצ׳ר שנתקע | המשתמש ננעל מחוץ למכשיר | גישה תמידית להגדרות המערכת, crash-safe fallback |

## 13. פרטיות

- אין חשבונות, אין אנליטיקה, אין פרסום ב־MVP. כל ההעדפות, הרשימה ו"המשך צפייה" נשמרים מקומית בלבד.
- בקשות ל־TMDB חושפות IP ושאילתות חיפוש. יש לציין זאת במדיניות הפרטיות.
- אין עוגיות (אפליקציה נייטיב). אם תתווסף אנליטיקה: רק אחרי הסכמה מפורשת, עם אפשרות משיכה.
- רשימת האפליקציות המותקנות נקראת מקומית ולא יוצאת מהמכשיר. בפרסום ב־Play נדרשת הרשאת `QUERY_ALL_PACKAGES` או `<queries>` מתאים, וזה עשוי לדרוש הצהרה לגוגל (**דורש אימות מול מדיניות Google Play**).
- מסמכי מדיניות פרטיות ותנאי שימוש יוכנו כטיוטה **ודורשים בדיקה משפטית**.

## 14. נגישות

- כל רכיב נגיש ב־D-pad, פוקוס בולט (הילת "אור נר"), סדר פוקוס הגיוני ב־RTL.
- TalkBack: `contentDescription` לכל כרטיס ואייקון, הכרזה על שינויי Hero.
- **ללא הבהובים מעל 3 פעמים בשנייה** (WCAG 2.3.1). "jump scares" חזותיים או קוליים רק כאופציה, כבויים כברירת מחדל.
- מתג אחד מכבה תנועה, ומכובד גם "הסרת אנימציות" של המערכת.
- ניגודיות AA לטקסט, גודל טקסט מינימלי מתאים למרחק צפייה (10-foot UI).

## 15. סיכונים פתוחים

1. **Google TV מגביל החלפת מסך בית.** במכשירי Google TV חדשים (למשל Chromecast with Google TV) אין תמיד אפשרות לבחור לאנצ׳ר אחר בהגדרות, ולעתים נדרשים פתרונות עקיפים (ADB, מיפוי כפתור Home). **דורש אימות על המכשיר שלך.**
2. **Deep links ל־Stremio** אינם API מתועד רשמית. ייתכן שיישבר בעדכונים.
3. **תוספי Stremio**: הלאנצ׳ר לא יתקין, ימליץ או יקשר לתוספים המספקים תוכן מפר זכויות. **נושא לבדיקה משפטית** אם האפליקציה תופץ.
4. **TMDB**: קרדיט חובה ותנאי שימוש. שימוש מסחרי דורש רישיון.
5. **פרסום ב־Google Play** של לאנצ׳ר: מדיניות הרשאות ותוכן. דורש אימות.

## 16. עדכון: רקעים, מידע ולאנצ׳ר אמיתי (בקשת משתמש)

- **מקור תמונות ומידע:** Cinemeta, שירות המטא־דאטה הציבורי של Stremio (ללא מפתח API): פוסטר, רקע, לוגו, דירוג IMDb, שחקנים, טריילר.
  נשלחים רק מזהי IMDb. מטמון בקובץ מקומי, רענון כל 24 שעות, עובד גם בלי אינטרנט. מתג כיבוי בהגדרות. **תנאי השימוש של Cinemeta והזכויות בתמונות דורשים בדיקה לפני הפצה ציבורית.**
- **עוד נתונים:** שורות "פופולרי עכשיו באימה", "מותחנים פופולריים", "תעלומות שכולם רואים" (כ־20 סרטים בכל שורה). לסרטים מהרשת אין מד פחד עריכתי, ולכן נעילת ההורים מתייחסת אליהם כרמה 5.
- **לאנצ׳ר:** בקשת תפקיד HOME מהמערכת (Android 10+), ואם המכשיר לא מציע אותה: שירות נגישות שמסנן רק את מקש Home ופותח את SCARY, וגם בעליית המכשיר. השירות לא קורא תוכן מסך.

## 17. מפתח TMDB אישי (אופציונלי)

- בהגדרות SCARY: שדה להזנת מפתח API v3 (32 תווים) או Read Access Token v4. המפתח נבדק מול TMDB לפני שמירה.
- **אחסון:** AES-256-GCM עם מפתח ב־Android Keystore. לא נכתב ללוגים, לא נשמר במטמון, נשלח רק ל־api.themoviedb.org (HTTPS, בלי redirect).
- **מה מוסיף:** שמות ותקצירים בעברית (he-IL), תמונות w1280/w500, שורות: אימה חדשה, הכי מדורגים באימה, מתח ותעלומה.
- **קרדיט חובה:** "This product uses the TMDB API but is not endorsed or certified by TMDB" מוצג בהגדרות. **תנאי השימוש של TMDB (שימוש אישי/מסחרי) דורשים בדיקה לפני הפצה.**

## 18. שפות: עברית, English, Português, Русский

- כל הממשק (122 מחרוזות) בארבע שפות. בחירת שפה בהגדרות SCARY במחזור, שמות השפות מוצגים בשפתן.

- גופנים: Karantina ו־Assistant ללא קירילית, ולכן ברוסית Oswald ו־Rubik (OFL).
- **התרגומים נכתבו ללא בודק שפה. מומלץ דובר פורטוגזית ודובר רוסית לפני הפצה.**

## 21. שדרוג: "הרשימה שלי", חיפוש קולי ושומר מסך אימה

**1. "הרשימה שלי"** (מקומי בלבד, עד 100 סרטים)
- בעמוד הסרט: כפתור "+ לרשימה שלי" / "✓ ברשימה שלי".
- במסך הבית: לחיצה ארוכה על OK בכל פוסטר מוסיפה או מסירה. TalkBack מכריז על הפעולה כ"לחיצה ארוכה".
- שורה חדשה "הרשימה שלי" אחרי שורת האפליקציות. לוגיקה ב־`core` (`MyList.toggle`) עם בדיקות.

**2. חיפוש קולי**
- כפתור מיקרופון ליד שדה החיפוש. הוא פותח את שירות זיהוי הדיבור של הטלוויזיה (`RecognizerIntent`) בשפת הממשק, והטקסט שמזוהה הופך לשאילתה.
- הכפתור מוצג רק אם יש בטלוויזיה שירות כזה. SCARY לא מבקשת הרשאת מיקרופון: השירות של המערכת מקליט ומחזיר טקסט.
- מקש החיפוש בשלט (`KEYCODE_SEARCH`), כשהוא נשלח לאפליקציה, פותח את מסך החיפוש.
- **פרטיות:** ההקלטה עוברת לשירות הדיבור של המכשיר (בדרך כלל Google), ולא ל־SCARY. זה מתועד במסך הפרטיות וב־`PRIVACY.md`.

**3. שומר מסך אימה (DreamService)**
- רקעים מ־52 הסרטים המאוצרים בלבד (לא מהשורות הפופולריות, שעלולות לכלול סרטי אקשן) מתחלפים לאט (כל 12 שניות, מעבר של 1.5 שניות, זום עדין) עם שם הסרט והלוגו.
- כשנעילת הורים פעילה, מוצגים רק סרטים מתחת לרמת הנעילה. כש"הסרת אנימציות" פעילה, אין זום ואין מעבר מדורג. אין הבהובים.
- אופליין: הסרטים המאוצרים עם רקע מחושב מהצבע שלהם.
- השירות מוגן ב־`BIND_DREAM_SERVICE`, כך שרק המערכת יכולה להפעיל אותו.
- בהגדרות SCARY: שורה "שומר מסך" שפותחת את הגדרות שומר המסך של הטלוויזיה (`ACTION_DREAM_SETTINGS`), עם הודעה אם הטלוויזיה לא מציעה אותן.

**בדיקות:** `MyList` ב־`core:test`; צילומי מסך ב־CI של עמוד סרט עם הכפתור החדש, של השורה במסך הבית ושל שומר המסך (דרך `Somnambulator` של SystemUI; **דורש אימות שהוא קיים באמולטור TV**).

## 22. "הפתע אותי", חיפוש ברשת ושמירת סרטים מהרשת

**1. "הפתע אותי"** (כפתור קובייה בשורה העליונה): סרט אקראי מהמאגר המאוצר, עד רמת הפחד של "הסרט של הלילה", ובלי סרטים נעולים. פותח את עמוד הסרט. הבחירה ב־`core` (`NightPick.surprise`) עם בדיקות.

**2. חיפוש ברשת** (רק כש"מידע מהרשת" פעיל)
- כשהשאילתה ארוכה מ־3 תווים, אחרי השהיה של 0.7 שניות: `catalog/movie/top/search=<שאילתה>.json` ב־Cinemeta (פרוטוקול התוספים של Stremio). הפורמט אומת בצילום מסך ב־CI (build 51): החיפוש "conjuring" החזיר 7 סרטים מהרשת.
- התוצאות מסוננות לאימה, מתח ותעלומה (כשהז׳אנרים ידועים), בלי כפילויות מול המאגר, עד 20 תוצאות. הן מוצגות בקטע "תוצאות מהרשת" מתחת לתוצאות המקומיות.
- ולידציה: אורך 3–60 תווים וקידוד URL מלא. התגובה עוברת את אותו פענוח חשדני של Cinemeta (HTTPS בלבד, אורך מוגבל).
- **פרטיות:** טקסט החיפוש נשלח ל־Cinemeta. זה מתועד במסך הפרטיות וב־`PRIVACY.md`. כשמידע מהרשת כבוי, לא נשלח כלום.

**3. שמירת סרטים מהרשת:** סרט שאינו מהמאגר המאוצר ונוסף ל"רשימה שלי" או לצפייה נשמר מקומית (`saved_movies.json`, עד 150). כך הוא לא נעלם כשהוא יוצא מהשורות הפופולריות.
- כשמידע מהרשת כבוי, כתובות התמונות של הסרטים השמורים מוסרות, כך שלא נטען כלום מהרשת.
- המרה `Cinemeta.fromMovie` / `toMovie` הלוך־חזור, עם בדיקה.

## 23. Release עם R8

- `assembleRelease` רץ בכל build עם R8 ו־shrinkResources. החתימה: מפתח release מ־secrets אם קיים, אחרת מפתח ה־debug, כדי שההתקנה תתעדכן מעל הגרסאות הקיימות.
- בדיקת עשן באמולטור: התקנת ה־release מעל ה־debug, מסך בית ועמוד סרט, וכישלון אם יש קריסה (buffer `crash` של logcat) או שהתהליך לא רץ.
- הפרסום (`latest-build`, ענף `apk-builds`) מחכה לבדיקה. `scary.apk` הוא ה־release ו־`scary-debug.apk` הוא הגיבוי.
- בטיחות: ה־release לא debuggable, כך שאין גישת `run-as` לנתוני האפליקציה דרך ADB, ונתיבי ה־debug לצילומי מסך כבויים בו.

## 24. ביצועים בטלוויזיה חלשה

- טוען התמונות (Coil) מוגדר לטלוויזיה: מטמון זיכרון של 20% (12% במכשיר עם מעט זיכרון), מטמון דיסק של 128MB, ופיקסלים בחצי גודל (RGB_565) כשהמערכת מסמנת את המכשיר כ־low-RAM או כשה־memoryClass הוא עד 192MB.
- התמונות נשמרות בדיסק גם כשהשרת מבקש זמן שמירה קצר, וכך הלאנצ׳ר מציג אותן גם בלי אינטרנט.
- **דורש מדידה על Xiaomi Mi:** זיכרון (`adb shell dumpsys meminfo io.github.diamondrubinny.scary`) וחלקות הגלילה.

## 26. צמרמורת, קרדיט, היצע גדול יותר ו"איפה לצפות" (אושר בתשובות, 22.10.2026)

החלטות המשתמש: קרדיט "Powered by SCARY · Open source · github.com/diamondrubinny/Scary"; הגנה ברישיון, בקוד וב־CI; זמינות לפי כפתורי חיפוש בלבד (בלי TMDB/JustWatch); אנימציית "צמרמורת".

### 1. קרדיט שקשה להסיר
- **רישיון:** מעבר מ־MIT ל־Apache-2.0 עם קובץ `NOTICE`. סעיף 4(d) מחייב כל עבודה נגזרת להשאיר את ה־NOTICE ולהציג אותו במקום שבו מוצגות הודעות כאלה. **זה מה שמחייב באמת. דורש בדיקה משפטית** (ובעיקר: האם כל הקוד שייך לבעל ה־repo).
- **קוד:** מקור אחד (`core/Credit.kt`) שהממשק משתמש בו, לא משאב מתורגם. כותרת SPDX עם הקרדיט בכל קובץ Kotlin, Gradle וסקריפט.
- **ממשק:** בתחתית מסך הבית, בהגדרות (אודות), בשומר המסך, במסך הפתיחה של סרט ובמסמכים.
- **CI:** סקריפט שנכשל אם הקרדיט חסר בקובץ קוד כלשהו, ב־NOTICE או ב־Credit.kt. בדיקת יחידה על הנוסח, ובדיקת UI שהקרדיט מוצג.
- **מגבלה (בכנות):** בקוד פתוח אי אפשר למנוע הסרה באופן טכני. מי שמשכפל יכול למחוק גם את הבדיקות. מה שנותן מנוף הוא הרישיון.

### 2. צמרמורת בזמן טעינת סרט
- בעמוד הסרט: הלוגו (או השם) עולה מהחושך, רועד קלות ומהבהב חלש פעמיים, ואחר כך מדי כמה שניות.
- בלחיצה על "צפייה": מסך מעבר קצר (כשנייה וחצי) עם הלוגו ברעד, ואז נפתחת האפליקציה.
- בטיחות: ההבהוב חלש (שקיפות 1 ← 0.55), על אזור הלוגו בלבד, לכל היותר 2 בשנייה (WCAG 2.3.1). "הסרת אנימציות" או אפקטים כבויים: בלי תנועה.

### 3. היצע גדול יותר (Cinemeta בלבד, בלי מפתח, רק מטא־דאטה חוקית)
- הקטלוגים המאומתים: `top`, `imdbRating`, `year` עם genre ו־skip (נבדק מול השרת).
- שורות: פופולרי באימה (2 עמודים), מדורגי אימה, מותחנים (פופולרי ומדורג), תעלומות, חדש השנה (ז'אנרים רלוונטיים בלבד). עד 40 סרטים בשורה.
- שמות שורות גם בערבית (היו חסרים בשורות מהרשת).
- **לא נכלל:** מקורות פיראטיים או תוספי Stremio עם סטרימים.

### 4. איפה לצפות: חיפוש באפליקציות המותקנות
- בעמוד הסרט: שורת כפתורים לכל אפליקציית צפייה מותקנת שמזוהה (Netflix, ‏Disney+‏, Prime Video, ‏Apple TV, ‏Max, ‏YouTube, ‏Plex, ‏Kodi, ‏yes, ‏HOT, ‏סלקום TV, ‏פרטנר TV ועוד), לפי שם חבילה ידוע או שם האפליקציה.
- אם האפליקציה תומכת בחיפוש (`ACTION_SEARCH`): "חיפוש ב־X" עם שם הסרט. אחרת: "פתיחת X".
- ב־Google TV: "חיפוש בכל הטלוויזיה" (חיפוש המערכת מראה איפה הסרט זמין).
- **דורש אימות במכשיר:** שמות החבילות של אפליקציות ישראליות ושל Apple TV, ואילו אפליקציות תומכות בחיפוש. לא מוצג "זמין ב־X", כי אין לנו מידע על זמינות.
