# התקנת SCARY על Xiaomi Mi

> המדריך נכתב בלי גישה למכשיר עצמו. כל שלב שמסומן ⚠️ **דורש אימות על המכשיר שלך**.

## 1. איזה דגם יש לך?

הגדרות ← Device Preferences (העדפות מכשיר) ← About (מידע) ← Model.

| דגם | מערכת | החלפת מסך בית |
|-----|--------|----------------|
| Mi Box S (דור 1, 2018) | Android TV 8/9 | אפשרית, בדרך כלל דרך ADB או Button Mapper |
| Mi TV Stick (Full HD) | Android TV 9 | כמו Mi Box S |
| Mi TV Stick 4K | Android TV 11 | כמו Mi Box S ⚠️ |
| Xiaomi TV Box S (דור 2 ואילך) | **Google TV** | מוגבלת יותר. מומלץ Button Mapper ⚠️ |

## 2. התקנת ה־APK

1. הורידו את הגרסה האחרונה מהקישור הקבוע:
   https://github.com/diamondrubinny/Scary/releases/download/latest-build/scary.apk
   (אם הריפו פרטי, צריך להיות מחוברים ל־GitHub. אפשר גם להוריד במחשב ולהעביר לטלוויזיה.)
2. אפשרו התקנה ממקורות לא ידועים: הגדרות ← Device Preferences ← Security & restrictions ← Unknown sources, ואשרו לאפליקציה שממנה תתקינו (למשל Send Files to TV או מנהל קבצים).
3. העבירו את הקובץ לטלוויזיה (Send Files to TV, דיסק און קי, או `adb install app-debug.apk`) והתקינו.
4. SCARY תופיע ברשימת האפליקציות של מסך הבית הרגיל. אפשר לפתוח ולבדוק אותה כבר עכשיו, בלי להחליף את מסך הבית.

## 3. הגדרה כמסך בית

### אפשרות א׳ (מומלצת, הכי בטוחה): Button Mapper

1. התקינו את Button Mapper מחנות Play.
2. אשרו לה את הרשאת הנגישות שהיא מבקשת.
3. מפו את כפתור Home בשלט לפתיחת SCARY.
4. מסך הבית המקורי נשאר מותקן ופעיל, ואפשר לבטל בכל רגע.

⚠️ בחלק מהשלטים לחיצה על Home מטופלת לפני שהאפליקציה רואה אותה. במקרה כזה מפו לחיצה ארוכה, או כפתור אחר.

### אפשרות ב׳ (מתקדמת): ביטול מסך הבית המקורי עם ADB

**סיכון:** אם SCARY תקרוס כשהמסך המקורי מבוטל, לא יהיה מסך בית. לפני שמתחילים, ודאו שאתם יודעים לחזור (שלב 4).

1. הפעילו מצב מפתחים: About ← לחצו 7 פעמים על Build.
2. Developer options ← הפעילו USB debugging (ובגרסאות חדשות גם Network/Wireless debugging).
3. מהמחשב, באותה רשת: `adb connect <IP-של-הטלוויזיה>:5555` ואשרו בטלוויזיה.
4. בדקו מה שם מסך הבית הנוכחי:
   `adb shell cmd package resolve-activity -c android.intent.category.HOME -a android.intent.action.MAIN`
   ב־Android TV זה בדרך כלל `com.google.android.tvlauncher` ⚠️, וב־Google TV `com.google.android.apps.tv.launcherx` ⚠️.
5. בטלו אותו: `adb shell pm disable-user --user 0 <package-מהשלב-הקודם>`
6. לחצו Home. אם מופיעה בחירה, בחרו SCARY ו"תמיד".

**חזרה למצב המקורי:** `adb shell pm enable <package>`

⚠️ ב־Google TV, עדכוני מערכת עשויים להפעיל מחדש את מסך הבית המקורי, ויש דיווחים שביטולו פוגע בפיצ׳רים אחרים. זו עוד סיבה להעדיף את אפשרות א׳.

## 4. Stremio

- SCARY מחפשת את Stremio לפי שם החבילה `com.stremio.one` ⚠️. אם Stremio מותקנת אצלכם אבל SCARY מציעה "התקנת Stremio", הריצו `adb shell pm list packages | grep -i stremio` ושלחו לי את התוצאה.
- "צפייה ב־Stremio" מנסה לפתוח ישר את עמוד הסרט. אם הגרסה שלכם לא תומכת בזה, Stremio תיפתח במסך הראשי ותופיע הודעה עם שם הסרט לחיפוש ⚠️.
- SCARY לא מתקינה ולא ממליצה על תוספים (Add-ons) ל־Stremio.

## 5. עדכונים

כל בנייה חדשה חתומה באותו מפתח ומספר הגרסה שלה עולה, ולכן מתקינים אותה מעל הקודמת וההגדרות נשמרות.
חריג אחד: אם התקנתם גרסה מלפני build 8, הסירו אותה פעם אחת לפני ההתקנה (החתימה השתנתה).

## 6. נעילת הורים

- הגדרות SCARY ← נעילת הורים ← בחירת קוד של 4 עד 8 ספרות, פעמיים.
- סרטים מרמת הפחד שבחרתם ומעלה מסומנים במנעול ודורשים קוד לפני פרטים, צפייה או טריילר. גם הכניסה להגדרות SCARY דורשת קוד.
- אחרי קוד נכון, הנעילה נפתחת עד שיוצאים מ־SCARY או עד 30 דקות.
- אחרי 3 ניסיונות שגויים יש המתנה: 30 שניות, ואז כפול בכל ניסיון, עד 15 דקות.
- הקוד לא נשמר כמו שהוא, רק hash עם salt.
- **מגבלה:** הנעילה לא נועלת את Stremio עצמה. להגנה מלאה השתמשו גם בבקרת ההורים של Google או של Stremio.
- **שכחתם את הקוד:** הגדרות המערכת ← Apps ← SCARY ← Clear data. זה מאפס את כל ההעדפות.
