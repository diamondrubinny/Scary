## פריסה
- להעלות את `site/index.html` (במקום `index.html` הקיים) ואת `site/og.jpg` לשרת של scary.network.
- **חובה: לעדכן גם את ה־Content-Security-Policy ב־nginx.**
  - השרת מתיר את ה־`<style>` וה־`<script>` המוטמעים רק לפי hash מסוג SHA-256.
  - בלי עדכון, הדפדפן חוסם את העיצוב ואת הסקריפט. כך זה נראה ב־31.10.2026: דף לבן־שחור בלי עיצוב ובלי החלפת שפות.
  - השורה המעודכנת נמצאת ב־`site/nginx-csp.conf`. היא מחליפה את שורת `add_header Content-Security-Policy` הקיימת.
  - אחרי ההחלפה: `sudo nginx -t && sudo systemctl reload nginx`.
  - כל שינוי עתידי בסגנון או בסקריפט דורש hash חדש. `tools/site/build.py` מדפיס אותו.
- **נבדק:**
  - עם ה־CSP הנוכחי: 2 חסימות, ואותה תקלה שראיתם בטלפון.
  - עם ה־CSP החדש: 0 שגיאות, העיצוב נטען ו־RTL עובד, בטלפון ובמחשב.
- מדיניות הפרטיות והצהרת הנגישות באתר נשארות טיוטה. **דורש בדיקה משפטית.**
