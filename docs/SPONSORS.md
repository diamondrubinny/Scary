## 1. הפעלת הפרופיל (פעם אחת)
1. github.com/sponsors ← **Get sponsored** ← בחירת החשבון האישי `diamondrubinny`.
2. מילוי פרופיל ופרטי תשלום: חשבון בנק או Stripe Connect, וטופס מס W-8BEN לתושב ישראל. **התאמה לדיווח מס בישראל (הכנסה מחו״ל, מע״מ) דורשת בדיקה מול רואה חשבון.**
3. הגשה לאישור של GitHub. עד שהפרופיל מאושר, הכפתור מוביל לעמוד שאומר שעדיין אי אפשר לתמוך.
